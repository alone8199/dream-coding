# 23 值的表示：variant 与引用语义

[中文](./23-value-representation.md) | [English](./23-value-representation.en.md)

运行时的值是求值器处理的数据。`dc` 用一个统一的 `Value` 类型表示所有值，它的内部是标准库的变体类型，可以保存七种不同的内容：空值、布尔值、数字、字符串、列表、字典和函数。这一篇说明这些值如何表示，以及它们的语义规则。

变体类型的好处是，同一个变量可以在不同时刻保存不同种类的值，而不需要动态分配一个基类对象。每个值在内存中占用的空间是固定的，检查它的种类也只是一次类型判断。这让求值过程的开销保持较低。

数字统一使用双精度浮点数。`dc` 不区分整数和小数，所有数字都是浮点数。这个设计让算术规则保持简单，但也意味着非常大的整数可能失去精度。对于梦境脚本来说，这通常不是问题。输出时，如果一个数字是整数且绝对值小于一千万亿，它会以整数形式显示，否则以最多十五位有效数字的形式显示。

字符串是不可变的字节序列。字符串的拼接、重复和切片都会生成新的字符串。索引访问返回的是单个字节，而不是单个字符，这对于包含多字节字符的中文文本来说需要注意。

列表和字典采用引用语义。这意味着，当你把一个列表赋值给另一个变量时，两个变量指向的是同一个对象。修改其中一个，另一个也会看到变化。这种语义与 Python 一致，它让函数可以方便地修改传入的容器，但也要求开发者注意共享带来的副作用。

字典的键统一为字符串。数字键会被转换为字符串，布尔值和空值也会被转换为对应的文本。字典在内部使用有序的映射存储，因此遍历时键是按字典序排列的，而不是按插入顺序排列。这一点在编写依赖顺序的脚本时需要特别注意。

函数也是一种值。它可以被赋值给变量，作为参数传递，也可以作为返回值。函数值内部保存的是一个可调用对象的指针，它既可以是用户定义的函数，也可以是 C++ 实现的原生函数。调用时，求值器不需要关心它的具体来源。

判断真假的规则遵循常见的约定：空值、假、零、空字符串、空列表和空字典为假，其他为真。这个规则让条件判断可以直接使用容器，比如 `if xs { ... }` 会在列表非空时执行。

相等比较的规则需要特别说明。基本类型比较的是内容，比如两个相同的字符串相等。但列表、字典和函数比较的是引用，只有同一个对象才相等。因此 `[1] == [1]` 的结果是假，因为它们是两个不同的列表。

总之，`Value` 的设计在简单性和表达力之间取得了平衡。它的规则不多，但足以支撑梦境脚本的大部分需求，并且让开发者能够清楚地预测每个操作的结果。
