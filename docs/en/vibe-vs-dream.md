# vibe coding vs dream coding

## Origin

vibe coding: you sit at the keyboard, shake it, and let an AI guess your mood.

dream coding: you close the IDE, shut your eyes, and let the compiler enter its REM cycle.

## Output

| Dimension | vibe coding | dream coding |
|---|---|---|
| Does it run? | Yes, but fragile | No, but it already ran in your dream |
| Code quality | Spaghetti that works | Utopia that doesn't |
| Maintainer | You + AI + some npm packages of unknown origin | Your subconscious |
| Docs | Generated README | Comments you forget after waking |

## Debugging

- vibe coding: copy the error, paste it to the AI, get a new error.
- dream coding: you wake up, see one line of segfault, and go find Freud.

## Final destination

- vibe coding ends at Stack Overflow.
- dream coding ends at Freud.

## Conclusion

Neither guarantees correct code. The difference: when vibe coding fails you get anxious; when dream coding fails you think "this might be a metaphor."

If you can only pick one, pick sleep.
