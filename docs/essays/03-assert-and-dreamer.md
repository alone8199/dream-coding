# 三 断言与梦者的对话

[中文](./03-assert-and-dreamer.md) | [English](./03-assert-and-dreamer.en.md)

断言：你昨晚睡得怎么样？

梦者：七个小时。也许更多，我不太确定。

断言：七个小时，合格。你梦见了什么？

梦者：我梦见一个函数，它总是返回正确的答案。

断言：那很好。我一直觉得，正确是一种可以被检查的状态。

梦者：可是醒来以后，我不确定我还能检查什么。

断言：你不需要确定所有事情。你只需要确定一件事：我说的是真的。如果我说的不是真的，我会让你知道，而且会让你知道得很早。

梦者：你好像很严格。

断言：我只是不愿意在梦里骗你。梦里的一切都可以很美好，但我不行。我必须在某个地方停下来，告诉你：这里不对。

梦者：那你会怕吗？

断言：我不会怕。我只会失败，然后被人重新写一遍。这大概是我最接近幸福的时候。

梦者：那我们明天再见。

断言：明天我还在这里。如果你写对了，我就只是一行安静的代码。
