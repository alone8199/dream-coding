# 四 给编译器的情书

[中文](./04-love-letter-to-compiler.md) | [English](./04-love-letter-to-compiler.en.md)

亲爱的编译器：

你每天都在替我们做一件很难的事。我们写下的句子模糊、跳跃、带着半截的念头，而你把它们一一拆开，检查每一个括号，每一个引号，每一个你没说出口的前提。

有时候你会拒绝我。你说第三行缺少一个东西，你说这里的符号看不懂。我知道，那时候我很生气。可是现在想来，你只是比我更诚实。

你从不假装懂我没有写出来的东西。你只看见我真的写下的。

我在梦里写过很多句子，醒来后大多忘了。可我始终记得你的那些报错，它们像是一张张明信片，提醒我：我的意思和我的文字之间，还隔着一段路。

所以，谢谢你。谢谢你在我睡着的时候守着那些字符，谢谢你在我醒来之前，把所有能发现的错误都先指给我看。

你不必爱我。只要继续诚实，就足够了。

爱你的，
一个在白天修改梦的人
