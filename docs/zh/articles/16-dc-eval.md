# 16 dc eval：一行梦

`dc eval` 是一个用来执行单行代码的命令。它接收一段字符串作为代码，立即在解释器中执行，并把结果输出到标准输出。它适合用来快速验证一个表达式，或者在不创建文件的情况下试验某个想法。

用法是：

```
$ dc eval 'print(1 + 2)'
3
```

由于 `eval` 不需要文件，它非常适合在终端中做小规模的探索。比如想知道某个内置函数的行为，可以直接运行 `dc eval 'print(range(3))'`，而不必先创建一个脚本。

与 `dc run` 不同，`eval` 的错误输出格式略有差异。它会输出 `line 行号: 错误消息`，并以退出码 4 结束，但不会输出段错误。这是因为 `eval` 更偏向白天的探索，它的使用者通常就在终端前，不需要仪式化的醒来输出。这个区别也说明了，`eval` 不属于完整的梦境流程，它是一个辅助工具。

`eval` 的代码是一个完整的程序片段，可以包含多条语句。例如：

```
$ dc eval 'let x = 2; print(x * 3);'
6
```

需要注意的是，`eval` 中的代码和文件中的代码运行环境是一样的。它可以访问所有内置函数，可以导入标准库模块，但它无法访问之前 `eval` 调用中定义的变量，因为每次调用都会创建一个新的解释器实例。

在实际使用中，`eval` 常用于检查标准库的行为。比如想确认 `math.floor` 对负数的处理，可以直接运行 `dc eval 'import math; print(math.floor(-2.5));'`。这种即时的反馈有助于快速建立对语言细节的直觉。

从设计角度看，`eval` 的存在是为了降低探索的门槛。梦境编程强调醒来后的解读，但白天的探索同样重要。`eval` 让开发者可以在白天快速验证假设，然后把确认过的想法写入梦境脚本，交给睡眠去推演。
