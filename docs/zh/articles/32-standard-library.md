# 32 标准库：math 与 dream

标准库是 `dc` 随附的一组模块，它们通过 `import` 加载，提供常用的数学函数和梦境相关的功能。标准库的目标是让常见的脚本不需要依赖外部代码，同时保持足够小，便于理解和维护。

`math` 模块提供了基本的数学工具。它包含两个常量：`pi` 表示圆周率，`e` 表示自然常数。它包含 `sqrt` 用于开平方，传入负数时会报 `ValueError`。它包含 `floor` 和 `ceil`，分别向下和向上取整。它包含 `abs` 用于取绝对值，`pow` 用于计算幂。`min` 和 `max` 比较一组数字，既可以直接传入多个参数，也可以传入一个列表。

下面的例子展示了 `math` 的常见用法：

```dc
import math;
print(math.sqrt(16), math.max(1, 9, 3), math.min([4, 2]));
print(math.floor(2.7), math.abs(-3));
```

`dream` 模块与梦境编程的流程直接对应。它的 `sleep` 函数接收睡眠的小时数，行为与命令行的 `dc sleep` 一致：默认八小时，少于七小时会报 `TimeoutError`。成功时它会输出进入快速眼动阶段的提示，并返回一个字符串。

`wake` 函数会输出段错误信息。它的效果与命令行的 `dc wake` 相同，都会输出 `Segmentation fault (dream dumped)`。把它放在脚本的末尾，就可以让脚本显式地宣告自己的醒来。

`dump` 是一个常量，它保存了段错误信息的文本。脚本可以用它来做比较，或者在需要时把它输出到其他地方。

`dream` 模块的存在让梦境脚本可以表达流程的一部分。例如，一个脚本可以先调用 `dream.sleep(8)`，然后执行一些计算，最后调用 `dream.wake()`。这样，整个脚本的结构就与梦境编程的流程对应起来了。

标准库中的其他功能，比如 `len`、`range`、`print` 等，是作为全局函数提供的，不需要导入。它们的使用频率更高，所以直接放在全局环境中。

需要注意的是，标准库的函数都是原生函数，它们的实现位于 C++ 代码中。这意味着它们的行为是固定的，不会因为脚本的不同而变化。如果需要修改某个函数的行为，只能通过修改运行时的代码，或者注册一个同名的模块来覆盖它。

总之，标准库在功能和规模之间取得了平衡。它提供了足够的工具来支持常见的梦境脚本，同时保持了简单的结构，让开发者能够快速理解每个函数的作用。
