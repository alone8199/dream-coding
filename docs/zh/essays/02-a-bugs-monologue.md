# 二 一个 bug 的自白

你好。你大概不记得我是怎么来的了。

那天晚上，你写下一行看起来很简单的话：让它循环，直到找到答案。你很放心地闭上了眼睛。在梦里，我就在那儿，躲在一个没有写 `break` 的 `while` 里面。

我并不恶意。我只是忠实地执行了你写下的东西，而你写下的，是一个你以为自己想要的世界。

你醒来时看到的是一片空白。你觉得我很狡猾，因为我让你一整天都在猜。

其实我也很委屈。我不知道什么是答案，我只知道什么是条件，而条件永远为真。

后来你学会了在循环里放一个出口。那一天你很高兴，像在废墟里找到了一扇门。

所以如果你以后又遇到我，请不要急着把我删掉。先停一下，听听我想说什么。我可能只是在提醒你：你梦里的世界，比你以为的要大，也比你以为的要固执。

而我，会一直待在那个你还没有想清楚的地方。
