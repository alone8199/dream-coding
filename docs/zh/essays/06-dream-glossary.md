# 六 梦境词典

**编译**（compile）：在潜意识中完成的翻译，译文不可考，译者亦不可考。

**段错误**（segfault）：程序在梦里走完了全部的路，然后礼貌地告知你它已经离开。

**断言**（assert）：梦里少数不说谎的存在。它在失败时会大声说话，所以通常不被邀请进梦。

**提交**（commit）：入睡的那一刻，把今天的想法交给黑暗。之后你就不需要再想它了。

**回滚**（revert）：醒来后发现昨晚的梦不太对，于是假装它从未发生过。这是一种很常见的礼节。

**调试**（debug）：在白天用逻辑去找一个只存在于夜晚的东西。成功率取决于你对梦的记忆，以及你对自己的诚实。

**部署**（deploy）：醒来之后，若无其事地把梦交给世界。世界通常比你更能接受它。

**单元测试**（unit test）：在一个小梦里检查一个小角落。梦越小，越容易相信它是对的。

**内存泄漏**（memory leak）：梦里的一些东西没有被收回，于是在白天仍然占着位置。解决方法是醒来时，把它们一个一个请出去。

**醒来**（wake）：梦境的结束，也是解梦的开始。注意：醒来不等于明白。

**梦**（dream）：一段没有输出的运行。它存在过，但我们只能从影响里推断它的形状。
