# 一 致段错误的颂歌

醒来的时候，屏幕上只有一行字。

它没有解释，没有行号，没有指向哪一个变量。它只是安静地告诉你：这里曾经有过一个梦，梦已经被倾倒了。

Segmentation fault。分段错误。听起来像是一种地质现象，像是大地在夜里裂开了一条缝，而你的程序恰好站在缝的边缘。

我们习惯把它当作失败。可是换个角度想，它其实是一份很诚实的告别。程序在梦里走完了它该走的路，然后把自己交还给内存，像一个不愿打扰任何人的客人，轻轻关上门。

所以，请对它温柔一点。

它不是在骂你，它只是在说：我已经来过了，而且已经完成了。剩下的，是醒着的你要去理解的东西。

愿每一次段错误，都是一场安静的落幕。愿每一个醒来的清晨，都有人读懂了梦里留下的那一行字。
