# vibe coding vs dream coding

## 起源

vibe coding 是你坐在键盘前，摇晃它，让 AI 猜你的心情。

dream coding 是你关掉 IDE，闭上眼睛，让编译器进入 REM 周期。

## 产出

| 维度 | vibe coding | dream coding |
|---|---|---|
| 代码能不能跑 | 能跑，但很脆弱 | 不能跑，但在梦里跑过了 |
| 代码质量 | 屎山 | 乌托邦 |
| 代码维护者 | 你 + AI + 一群不明来历的 npm 包 | 你的潜意识 |
| 文档 | 生成的 README | 醒来后忘掉的注释 |

## 调试

- vibe coding：复制报错，粘贴给 AI，AI 给你一段新的报错。
- dream coding：你醒来，看到一行 segfault，然后去找弗洛伊德。

## 最终归宿

- vibe coding 的尽头是 Stack Overflow。
- dream coding 的尽头是弗洛伊德。

## 结论

两者都不能保证代码正确。区别在于：vibe coding 失败时你会很焦虑，dream coding 失败时你会觉得"这可能是一个隐喻"。

如果你只能选一个，请选择睡觉。
